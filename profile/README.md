# Daena

**The truth layer of the internet.**

Today's web is built for humans. Agents scrape, parse, and hallucinate their way through it because it was never designed for them. Daena is an open protocol for an internet where every publisher exposes a signed, structured, verifiable source of truth — read natively by agents, and rendered for humans on demand.

In Avestan, *daena* means *one's truthful self, made visible*. That is what every publisher commits to when they join the protocol.
